Repositório com exercícios e algoritmos desenvolvidos em Portugol durante meus estudos de lógica de programação e algoritmos e fundamentos da computação.

---

## 🧠 Sobre o repósitorio
Este repositório reúne atividades práticas criadas com o objetivo de:

* `Desenvolver o raciocínio lógico;`
* `Aprender estruturas básicas de programação;`
* `Praticar resolução de problemas computacionais;`
* `Consolidar conceitos fundamentais da área.`

## 📂 Estrutura do repositório
Os exercícios estão organizados por temas, incluindo:

* `Estruturas condicionais (se, senao);`
* `Variáveis e tipos de dados;`
* `Operadores lógicos e matemáticos;`
* `Algoritmos básicos.`

## 🛠️ Tecnologias e ferramentas
* **Linguagem:** `[Portugol];`
* **IDE Sugerida:** `[Portugol Studio, Eclipse].`

## 🚀 Como utilizar

* **Passo 1:** Para clonar este repositório e ter acesso aos códigos localmente, utilize o comando abaixo.

   `git clone https://github.com/michelevitorina/algoritmos-portugol.git`

* **Passo 2:** Abra os arquivos em um interpretador de Portugol (como Visualg ou Portugol Studio).

* **Passo 3:** Execute e explore os algoritmos!

## 📌 Observações

* **Os códigos foram feitos com fins educacionais;**
* **Podem conter diferentes formas de resolução para o mesmo problema.**
